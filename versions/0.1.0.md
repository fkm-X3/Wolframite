For the 0.1.0 to release the Tungsten backend compiler will have to emit binary objects directly then it will invoke the linker Ferro (short for Ferrotungsten) which isn't front facing in the way lld or gnu ld is, its internal but can be accessed by args in the Wolframite syntax. There will also have to be good enough documentation so that someone that knows basic programming principles can pick up the language.

Checklist for 0.1.0:

- [x] Tungsten emits binary objects.
- [X] Ferro linker links binary objects to ether ELF64 (Linux) or PE/COFF (Windows).
- [X] Ferro linker can be talked to via Wolframite syntax.
- [x] Learning docs for Wolframite. 
- [ ] Integrated Test Runner
- [ ] Built-in Formatter
- [ ] Zero-Config Cross-Compilation (this one is mostly already done, just needs a bit more testing)
- [ ] Human-Readable Compiler Errors
- [ ] Smeltfile for build config (like make)
- [ ] wfr-bin/ for binary's
